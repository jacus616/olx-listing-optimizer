# OLX Moderation — Safe vs Unsafe Words

## ❌ TRIGGER WORDS (avoid in title AND description)

These words/patterns are known to trigger OLX's automated moderation (Mobius system) or suggest spam/scam behavior:

### Spam/Urgency Triggers
| Word/Phrase | Why Flagged | Safe Alternative |
|-------------|-------------|------------------|
| okazja | Subjective, overused by spammers | Omit |
| hit | Unverifiable superlative | Omit |
| super / super okazja | Spam indicator | Omit |
| ekstra / ekstra okazja | Spam | Omit |
| najlepsza cena | Unverifiable claim | Omit |
| najtaniej | Unverifiable claim | Omit |
| tylko dziś | False urgency | Omit |
| ostatnia sztuka | False scarcity | Omit |
| kup teraz / kupić od razu | Pressure tactic | Omit |
| pilnie / sprzedam szybko | Suggests scam/escape | Omit |
| hit tygodnia | Spam | Omit |
| rewelacja | Subjective spam | Omit |
| idealny / idealnie (excessive use) | OK once, not 3x | Use "stan bardzo dobry" once |

### Formatting Triggers
| Pattern | Why Flagged | Safe Alternative |
|---------|-------------|------------------|
| ALL CAPS TITLE | Shouting = spam | Normal capitalization |
| Multiple exclamation marks "!!!" | Spam | Single period |
| Excessive emojis in title | Bot-like | No emojis in title |
| Repeated words "okazja okazja okazja" | Keyword stuffing | Omit |
| Special characters for attention "★ ♦ ♫" | Bypasses text filters | Omit |

### Contact/Off-Platform Triggers
| Pattern | Why Flagged | Safe Alternative |
|---------|-------------|------------------|
| Phone number in description | Bypass OLX messaging | Use OLX chat |
| Email address | Bypass platform | Use OLX chat |
| External URLs (allegro, eBay, etc.) | Competitor redirect | Omit |
| "zadzwoń / napisz SMS" | Off-platform contact | "napisz przez OLX" |

### Scam Indicators
| Word/Phrase | Why Flagged | Safe Alternative |
|-------------|-------------|------------------|
| wymiana na coś | Vague trade = scam risk | Only if specific trade offered |
| zamienię | WTT without details | Omit or be specific |
| sprzedaję hurtem | Business without business account | Omit |
| odzysk / likwidacja | Stolen goods suspicion | Omit |
| bez paragonu/faktury (when selling new) | Grey market | Include if available |

## ✅ SAFE ALTERNATIVES

### Instead of "okazja/hit" — use:
- "używany, pełna sprawność"
- "stan bardzo dobry, gotowy do użytku"
- "dobrze zachowany, wszystko działa"
- "kompletny zestaw, szybka wysyłka available"

### Instead of urgency — use:
- "cena do negocjacji" (if negotiable)
- "możliwość wysyłki InPost / OLX delivery"
- "odbiór osobisty [miasto] lub wysyłka"

### Instead of superlatives — use:
- Specific facts: "bateria trzyma 6h gry"
- Verifiable claims: "pierwszy właściciel, faktura dostępna"
- Honest condition: "drobna rysa na obudowie (zdjęcie), ekran bez uszkodzeń"

## ✅ SAFE EMPHASIS TECHNIQUES

| Technique | Example |
|-----------|---------|
| Section headers | "SZCZEGÓŁY TECHNICZNE:", "STAN TECHNICZNY:" |
| Bullet points | "- Procesor: Snapdragon 865" |
| Specific numbers | "Bateria: 5000 mAh" |
| Comparisons | "Ten sam procesor co [Popular Model]" |
| Honest flaws | "Drobna rysa na spodzie, nie wpływa na działanie" |
| Complete package list | "W zestawie: ... ..." |
| Clear location | "Lokalizacja: Warszawa, Mokotów" |

## 📊 OLX ALGORITHM FRIENDLY PATTERNS

These help with search ranking:

1. **Title contains exact model name** — "Retroid Pocket Flip 2" not "Retro konsola"
2. **Key specs in title** — "8GB RAM", "128GB", "czarny", "Ice Blue"
3. **Description 400-1000 chars** — too short = spam, too long = skip
4. **Natural keyword usage** — mention compatible systems once or twice
5. **Structured format** — headers, lists, sections (OLX NLP rewards organization)
6. **Unique per listing** — never copy-paste identical descriptions
7. **Accurate category** — post in correct subcategory
8. **Location set precisely** — not "cała Polska" for local pickup
