# Audit Checklist — Detailed Scoring Guide

## Title Scoring (20 points)

| Criterion | Points | Check |
|-----------|--------|-------|
| Contains exact brand name | +3 | ✅/❌ |
| Contains exact model name | +3 | ✅/❌ |
| Contains key spec (RAM/storage/color) | +4 | ✅/❌ |
| Length ≤ 70 chars | +5 | ✅/❌ |
| No trigger words | +3 | ✅/❌ |
| Natural Polish phrasing | +2 | ✅/❌ |

## Description Scoring (40 points)

| Criterion | Points | Check |
|-----------|--------|-------|
| Length 400-1000 chars | +10 | ✅/❌ |
| Structured with headers | +5 | ✅/❌ |
| Bullet points used | +5 | ✅/❌ |
| Technical specs included | +10 | ✅/❌ |
| Honest condition description | +5 | ✅/❌ |
| Complete package list | +5 | ✅/❌ |

|-----------|--------|-------|

## Score Interpretation

| Score | Grade | Action |
|-------|-------|--------|
| 90-100 | 🟢 Excellent | Ready to publish, minor tweaks optional |
| 75-89 | 🟡 Good | Fix highlighted issues, then publish |
| 50-74 | 🟠 Needs work | Multiple issues, follow suggestions |
| <50 | 🔴 Poor | Rewrite recommended |

## Common Issues & Fixes

| Issue | Impact | Fix |
|-------|--------|-----|
| Title too long | Truncated in search | Cut to ≤70 chars, keep brand+model |
| No specs in description | Low search ranking | Add 5-7 key specs as bullets |
| Missing package list | Buyer distrust | List every item included |
| "okazja/hit" in title | Moderation flag | Remove, use neutral language |
| No location | Reduced local visibility | Add city/region |
| No shipping info | Missed buyers | Add "wysyłka InPost" or "odbiór osobisty" |
| Vague condition | Buyer questions | "bez rys na ekranie, bateria 85% pojemności" |
| Copy-paste duplicate | OLX detects, lowers ranking | Rewrite in own words |
